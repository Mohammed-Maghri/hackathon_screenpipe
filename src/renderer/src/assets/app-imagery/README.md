# Application marks

Flat SVG marks replace the former rendered 3D PNG badges. Keep the artwork's native proportions and colors; use the shared `AppMark` component for sizing, aliases, accessible names, and neutral framing. Files are bundled locally; no icon API or runtime network requests.
