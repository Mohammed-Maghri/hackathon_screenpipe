# NOVA product photography

`products.png` was created with the built-in image generation tool for this local demo. The six product photographs share one 3 × 2 sheet; the UI displays individual cells with CSS background positioning. No external image service is needed at runtime.

Generation prompt:

> Use case: product-mockup. Create one catalog contact sheet image for the NOVA clothing store dashboard: exact 3-column by 2-row grid of equal square cells, entire image aspect ratio 3:2. Six photorealistic isolated product photos, one centered per cell with generous padding and identical pale warm grey background, no visible dividing lines. Row 1 left: black oversized pullover hoodie front view; row 1 middle: plain white short sleeve t-shirt front view; row 1 right: beige cargo pants front view. Row 2 left: black baseball cap three-quarter view with small white NOVA embroidery; row 2 middle: pair of grey running sneakers three-quarter view; row 2 right: tan canvas tote bag front three-quarter view. Soft professional studio lighting, subtle contact shadows, realistic textile texture, clean ecommerce product photography, no other text, no humans, no props. Each product completely contained within its own cell; accurate evenly spaced grid for CSS sprite use.
